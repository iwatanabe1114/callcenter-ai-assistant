コールセンターAIアシスタントの仕組み

質問から回答までの5つのステップ

質問を入力
→
言葉を広げる
→
資料を検索
→
AIが回答作成
→
結果を表示

質問してから回答が出るまで、この5つの処理が自動で行われます

1 OPが質問を入力する

オペレーターがチャット欄に質問を入力します。話し言葉でOKです。

入力例：「定期便を2回で解約したいと言われました。どうすればいいですか？」

アプリはまず、質問文から「言い回し」を取り除きます。

  • 「と言われました」「どうすればいいですか」などの定型フレーズを除去
  • 検索に関係のない部分を落として、検索精度を上げるため
処理後：「定期便を2回で解約」→ これが検索キーワードになる
2 AIが検索キーワードを広げる（クエリ拡張）

質問の言葉だけだと、マニュアル側の表現と微妙に違って見つからないことがあります。
そこで軽量AI（Claude Haiku）が、同じ意味の別の言い方を自動で追加します。

例：質問に「返品」と書いてあった場合
→ AIが「返送」「キャンセル」「返金」などの関連語を追加

ただし、追加された言葉は元の質問より低い重要度で扱います。
「対応」「手続き」のような一般的すぎる語は自動的に除外されます。

なぜ重要度を分けるのか：追加した言葉を同じ重さで扱うと、 関係のない資料まで大量にヒットして、かえって精度が落ちるため。
3 キーワードでマニュアル・資料を検索する

ステップ2で作ったキーワードをもとに、4種類の資料を横断検索します。

  • キャンペーン・施策（優先度：高）
  • マニュアル・回覧板（優先度：やや高）
  • 料金表（優先度：標準）
  • 商品情報（優先度：やや低）

検索方式はBM25（キーワード検索）です。日本語は2文字ずつの組み合わせ（bi-gram）で一致を調べます。

検索結果は一致度のスコア順に並び、上位6件（設定で変更可）をAIに渡します。

ポイント：キャンペーン情報は最新で重要なことが多いため、 同じスコアならキャンペーンが上に来るよう優先度を付けています。
4 AIが資料をもとに回答を作成する

検索で見つかった資料をAI（Claude Sonnet）に渡して、回答文を作成させます。

AIへの指示（守らせているルール）：

  • 渡された資料の中身だけを根拠に答える。資料にないことは絶対に書かない
  • 回答は「結論」（1〜2文）と「条件・詳細」に分ける
  • 金額や日数は資料の数字をそのまま引用する。計算・丸め・推測はしない
  • 資料に答えがない場合は「見つかりませんでした」と正直に返す
  • 本社確認が必要な場合はその旨を注意として表示する
AIが作る回答の構成：
・結論：「定期便の解約は次回発送予定日の10日前まで受け付けます。」
・条件・詳細：「回数縛りのあるコースは、規定回数の受け取りが完了しているか確認してください…」
・注意：「差額が発生する場合があります。」
5 結果を画面に表示する

OPの画面に以下の3つが表示されます：

  • 結論 ー 大きく表示。これだけ読めばお客様に伝えられる
  • 条件・詳細 ー 必要に応じて開いて確認する部分
  • 参考にした資料 ー 元のマニュアルへのリンク。「本当にそう書いてあるか」自分の目で確認できる
重要：参照元の資料リンクはAIが作ったものではなく、 検索結果からプログラムが機械的に表示しています。AIの作文ミスを防ぐためです。

回答品質を上げるには

1. マニュアルの内容を充実させる

AIは渡された資料の中身だけを根拠にします。マニュアルに書かれていないことは回答できません。 「答えが見つかりませんでした」が多い質問は、対応するマニュアルの追加が効果的です。 管理画面の「答えが見つからなかった質問」一覧を参考にしてください。

2. マニュアルの表現を統一する

同じことを「解約」「退会」「停止」とバラバラに書いていると、検索で見つかりにくくなります。 よく使う言葉をマニュアル内で統一すると精度が上がります。

3. 質問の仕方を工夫する

具体的なキーワードを含む質問のほうが精度が高くなります。

✗ 「どうしたらいいですか？」
✓ 「メグレアの定期便を初回で解約したい場合の手順は？」

4. 検索対象のジャンルを絞る

サイドバーの「探す資料の種類」で、必要なジャンルだけに絞ると、 関係のない資料にヒットしにくくなり精度が上がります。

5. 古い情報を定期的に整理する

終了したキャンペーンや古い回覧板が残っていると、それが回答に使われることがあります。 現在は180日を超えた情報は自動的に除外されますが、それより前でも不要な情報は整理すると効果的です。
